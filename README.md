# FITiX

FITiX is a mobile-first fitness, nutrition and wellbeing tracker.

## Product principles

- User-owned records: never invent measurements, meals, activity or health data.
- Food-photo analysis is an estimate and must be reviewed by the user before saving.
- Health and nutrition guidance is supportive, cautious and never a substitute for professional care.
- Private-by-design application data, even while this source repository is public.
- Accessible, responsive and installable PWA experience.

## Planned stack

- Web: React, Vite, TypeScript, Tailwind CSS, PWA
- API: Node.js, Express, TypeScript
- Database: PostgreSQL (Neon-compatible)
- Validation: Zod
- Charts: Recharts
- Tests: Vitest, Testing Library, API integration tests
